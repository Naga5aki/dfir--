# 工具输出有效性"三关"（格式自检 / 对照实验 / 负控制）

> 来源：SecurityLab Case-005（2026-09-29），由一条真实主弯路归纳——把工具对**任意图像**的固有输出当作"大体量载荷"深挖 40+ 分钟。迁移验证：原题 + 对照实验（普通输入同构输出）+ 负控制全组。

## 规则
**任何工具对样本给出的"成功"输出，在作为证据消费之前必须过三关：**

1. **格式自检**——先取得该工具"正确输出应该长什么样"的样例（工具自带 demo / 说明书示例 / 已知产品样本），再对照：
   - 有无结构头 / 长度前缀 / 终止符 / 可读前缀？
   - 输出与样例的格式是否同构？不符 → 输出存疑。
2. **对照实验**——把同一工具跑在**同类普通输入**上（合成噪声图 / 无关自然图 / 普通文本）：
   - 若同样产生**同构输出**（同尺寸 / 同分布 / 同样"像数据"）→ 该输出形态是工具的固有行为，**不构成载荷证据**；
   - 只有"真实载体 vs 普通输入"在**格式痕迹**上可分（如仅真实产品含约定包装），输出才可作为线索。
3. **负控制**——错误参数 / 错误输入下输出必须可区分地失败、退化或与正确输出不一致；若错误输入也"成功"，该工具/路线没有区分力。

## 执行纪律
- 三关不足即不得继续"消费"该输出（渲染 / 解码 / 反编译解读都算消费）；修正尝试（换模式 / 换参数）**≤2 轮**，然后切换结构假设。
- **强切换信号**：需要先反编译 / 复刻工具引擎才能继续解读输出——说明该输出本身没有被验证，方向大概率错了。
- 停止条件：同一路线连续 3 次运行无（格式痕迹 ∨ 对照差异 ∨ 可达明文）任一信号 → 立即转向"载体关系 / 容器判定 / 网格提取"等结构分支。

## 适用范围
- 一切隐写 / 解码工具：空白隐写、图像隐写（嵌入 / 放大 / 差分各模式）、音频容器工具、压缩层工具等。
- 同样适用于"工具说 OK"的场景：退出码 0、无报错、产出体积很大，都不构成正确性证据。

## 与其他条目的关系
- 本规则是证据边界纪律在**工具输出**上的操作化：工具成功输出 = Observation，不是 Conclusion。
- 与"双实现交叉验证"配合：两个实现都要先各自过格式自检，才谈得上互为验证（共享错误假设的双实现会互相"证明"）。
- 载体基扫（零成本，各线各 1 次）产生候选；三关决定候选是否成立——两者顺序执行，互不替代。
