# 电子数据取证笔录草稿

解题提交不要调用本技能。没有单位模板时声明这是通用草稿，不冒充制式文书。

## 模式

只根据实际作业选择要素，不自动决定正式文书名。四种模式：现场勘验、远程勘验、电子数据提取、电子数据检查。要素见 `references/four-record-types.md`。

## 规则

- 缺字段写 `〔待确认：字段〕`，不用示例值，不用“某某”。
- 哈希逐字抄录，不补位，不改大小写后宣称为原值。原文、镜像、导出目录、封存载体的校验值分开写。
- 密码、令牌、密钥不进正文。
- 模型不能确认在场、签名、封存、移交。
- 不得把征求意见稿写成已生效依据。《公安机关办理刑事案件电子数据取证规则》2019-02-01 起施行这句话只是待核实依据，不能当作已经核过的现行法。
- 赛题提交口径不得写入笔录正文。
- 不提供绕过认证、提权或规避审计的方法。只记录用户已经提供的作业过程。

## docx

用户要求 docx 时，用本技能目录的 `scripts/md_to_gongwen_docx.py`。先运行 `python -I -c "import docx"`。失败就交付 Markdown，并写“docx 未生成”。不要安装依赖，不要宣称已经生成。
