# 资金流水本地分析

本环境没有 WebMatrix。不要调用 WMX，不要编 `/case/datasource` 一类虚拟路径。

## 流程

1. 只读用户给出的文件。不把源文件复制进工作区，不改源文件。
2. 用 `python -I` 读 CSV、TXT、TSV、XLSX。PDF 没有现成本地解析器时写“未取到”，不要安装软件。
3. 先报编码、表头、行数、时间范围和借贷方向字段。字段对不上就停，不猜列。
4. 回答用户的那一个问题。单题不要读 references/bill-flow-template.md。只有用户要求完整报告时才读模板。
5. 证据定位是文件路径、工作表和行号。
6. 和流量交叉时，两边都要有回执。一边有记录只写“待交叉”。
7. 内部转账、冲正、退款是否去重必须写明。

## 口径

- 交易总金额 = 转入 + 转出。
- 交易净额 = 转入 - 转出。
- 未指定时区时声明 `+8`，不要静默换算后覆盖原值。
- 战法命中不是违法认定。
- 未命中不是确认无异常。未执行、失败、仍在运行不能写成未命中。
- 不凭摘要、频率或路径认定身份、权属或主观目的。

规则命中只是核查线索。金额写币种，比例写分母。
