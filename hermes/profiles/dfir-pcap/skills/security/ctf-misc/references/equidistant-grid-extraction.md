# 等距/周期性像素网格提取（图像载体 → 提示/子文件）

> 来源：SecurityLab Case-005（2026-09-29）。迁移验证：原题 + 迁移变体（新载图/新起点/新步长/新块尺寸逐字节复原）+ 负控制（错误步长与期望产物字节一致率≈随机）。
> 适用：CTF Misc 图像隐写的一个结构化族——隐藏内容（文字提示、小图、子文件）按**固定网格采样**写入载体像素。

## 识别信号（何时优先试这一族）
- 图像载体与另一数据文件**成对出现**（命名同源、同一"故事链条"），或题面提示"找提示/密码/密钥"。
- 常规位平面 / LSB / 工具快扫无果——大图（≥720p）足以承载低密度网格冗余，浅层往往干净。
- 已知本机工具族含"等距像素 / 网格"类提取能力而尚未启用（基扫遗漏检查）。

## 参数模型（先记模型，具体值永远是案件特例）
- 起点 `(x1, y1)`：通常为小偏移（几像素级）。
- 步长 `(dx, dy)`：网格间距（"每隔多少像素取一点"）；由题目提示 / 工具默认值 / 周期检测得出，不得从单一样本概括。
- 块尺寸 `(sx, sy)`：每个网格点取多少像素（1×1 最常见）。
- 终点 `(x2, y2)`：按"步长对齐且块不越界"推导：
  `x2 = x1 + dx * ((W - x1 - sx) // dx)`（y 同理）——不要凭感觉截断。
- 输出尺寸 = (列数×sx) × (行数×sy)；采样顺序为行优先（y 外层、x 内层）。

## 提取流程
1. **工具基扫先行**：对载体跑一遍零成本基扫（本机 CTF Misc Arsenal 含等距/网格类提取器；勿因"看起来不像"跳过）。工具参数常与题目约定一致。
2. **自写提取器复算**：本 skill `scripts/grid_extract.py`（纯标准库）按同一参数复算；两个实现输出必须逐字节一致。
3. **后处理再判读**：低对比度/抗锯齿文本 → 亮度阈值二值化（多阈值各试一次）+ 去抖动放大（最近邻 ×6~×14），**逐字符**人工确认（注意冒号等标点）。
4. **产物按语义进入下一层**：如 `<label>:<value>` 指示串 → 先过格式自检，再按其语义使用（口令 / 容器 / keyfile 指向等）。

## 验证与负控制
- 正：提取图逐字符可读 + 产物驱动下游链路成功（如容器解锁通过）。
- 负控制（必做）：**错误步长**同法提取 → 与正确产物字节一致率应≈随机（本案负控制实测一致率处于随机量级）；错误参数仍然"看起来像图"不构成通过依据。
- 双实现：工具路径与自写脚本路径输出一致后才采信。

## 边界与替代解释
- 真实图像边缘的天然周期性可造成"伪网格"输出——判据是"逐字符可读 + 下游可用"，不是"像"。
- 同类采样族还有 Hilbert / 蛇形 / 随机置换等；本规则只覆盖**等距网格族**，失败后回到结构假设层（载体的其他用途 / 容器判定）。
- 具体参数值、坐标、尺寸属于案件特例，不得写入正式库；可迁移的只有模型与流程。
