# VeraCrypt/TrueCrypt 类容器：判定与离线解锁链

> 来源：SecurityLab Case-002（字节流重建链）+ Case-005（离线解锁链，2026-09-29）。迁移验证：原题 + 迁移变体（换 PRF / 口令 / keyfile / 布局）+ 负控制组。
> 本文件只写**通用格式事实与流程**；所有样本特定值（口令 / 哈希 / 尺寸 / CRC 值）不得转录。

## 判定信号（什么文件应视为候选容器）
- 整尺寸（512B 对齐，常见 ≥1MiB）、**纯高熵、无任何签名**。
- 「无签名」不是排除条件而是**符合特征**：该族按设计不留明文字段（区别于有魔数的容器族）。
- 成对文件（载体 + 数据）先假设同一链条：载体产提示（可能含口令 / keyfile 指向），数据 = 容器。
- `file` 的高熵标签不构成任何判据（既不证明、也不否定）。

## 格式要点（离线实现所需的全部结构事实）
- 布局：`[salt 64B][加密头部 448B][…填隙…][数据区][尾部备份头]`；头部字段**大端序**。
- 头部明文字段（解锁后可见）：magic `VERA`；version[4:6]；required[6:8]；**主密钥区 CRC32[8:12]**；volume_size(BE64)[36:44]；**enc_area_start(BE64)[44:52]**；**enc_area_len(BE64)[52:60]**；**主密钥区 master keys[192:256]**；**头字段 CRC32[188:192]**。
- 校验语义：`CRC32(头[0:188]) == 头[188:192]`（头有效性）且 `CRC32(头[192:256]) == 头[8:12]`（主密钥区有效性）。**双 CRC 通过 = 密钥链正确的事实级证据**（不需要挂载/驱动；离线可判）。
- 新版布局的数据区起点可为 **128KiB 量级**（经典布局为 512B）——不得硬编码，以 `enc_area_start` 字段为准。

## KDF 与 keyfile
- PBKDF2（HMAC-<PRF>）→ 64B 派生键；**PRF 与迭代数以官方源码参数表为准**（已实测组合含 SHA-512@500000、RIPEMD160@500000；PIM 与其他 PRF 未全验证）。实现优先 `hashlib.pbkdf2_hmac`（C 速度），异常再回退手写 PBKDF2。
- **keyfile 池算法（官方 Keyfiles.c）**：维护 64B（口令 >64B 时 128B）池。对 keyfile 每读 1 字节：更新流式 CRC32，再把该 CRC 的 4 个字节（高→低）依次**累加**进池，写指针循环前进。
- **口令混合**：keyfile 存在时，实际口令 = 逐字节相加版本——前 min(len(pw), 64) 字节 = (口令字节+池字节)&0xFF，其余 = 池字节；无 keyfile 则直接用口令字节。
- keyfile 必须是**原始文件本体**；由载体派生的文件（提取图等）作 keyfile 应按失败处理（负控制消歧）。

## XTS（该族自定变体——不要按通用 XTS 直觉实现）
- 数据单元固定 **512B**；每单元 32 个 AES 块。
- 单元 tweak：`T0 = E(k2, LE128(单元号))`；单元内逐块更新：**128 位左移 1 位；若旧最高位为 1，最低字节 XOR 0x87**。
- 头部区解密 = 把 448B 当**单元 0 上的连续链**（不按 512B 换单元）。
- 数据区单元号基准：**容器绝对扇区**（头部区占单元 0）与「相对数据区」两种都实测，用结构信号裁定（如 FAT 尾标 `55 AA` / 文件系统字段自洽）。
- **常见实现错误症状**：位移/方向写反 → 第 1 块解密正确、其后全错——见此症状先怀疑 tweak 链实现，而不是数据本身。
- 数据区解密用**头部主密钥对**（k1=master[0:32], k2=master[32:64]），**不是**口令派生键。派生键的两种先后排列（dk01/dk10）都过一遍头部魔数即可判定。

## 解锁与产物验收流程
1. 读 salt 与加密头部 → 试 PRF/迭代表 × keyfile 开关 × k-order → 判据：`VERA` + 双 CRC。
2. 头部字段给出布局 → 数据区解密 → 产物必须过**文件系统结构闭环**（引导扇区 OEM/BPB 断言、根目录条目、文件本体哈希）。
3. 答案回溯到**文件系统级实体本体**，不采信字符串扫描命中。

## 负控制组（设计照抄，值不照抄）
- 正确口令 + 无 keyfile → 必须失败（证明 keyfile 必需）；
- 错误口令 + 正确 keyfile → 必须失败；
- 正确口令 + 错误 keyfile（用派生文件充当）→ 必须失败；
- 正控制复查（全对）→ 必须成功。

## 执行入口与依赖
- `scripts/vera_unlock.py`（本 skill）：纯 Python + pycryptodome（本机 Python 3.12 环境自带）。示例：
  `python vera_unlock.py --volume <vol> --keyfile <kf> --password <pw> --dump-data out.bin [--extract dir]`
  - `--prf auto` 自动遍历参数表；成功打印 `UNLOCK OK` + 头部字段 + 双 CRC；
  - `--extract` 解析 FAT12/16 根目录并导出文件本体（FAT 场景）。
- 官方源码锚点（实现对照）：`Xts.c`（tweak 链）、`Keyfiles.c`（池算法）、`Pkcs5.c`（PRF/迭代表）。
