# 四类笔录要素

单位模板优先。下面只保留要素，不填示例人员、单位、时间或哈希。

## 现场勘验

现场位置、设备与网络原始状态、实际保护措施、发现的设备介质和编号、现场查看或固定的动作和结果、结束时的处置状态。

## 远程勘验

目标名称和定位信息来源、勘验端设备与工具版本、系统时间及时区、访问方式和授权身份来源。正文不记录密码、令牌或密钥原值。记录访问顺序、截图或录屏编号、下载或固定的数据来源、数量、位置和校验值，以及失败、中断和无法复现。

## 电子数据提取

对象标识、持有人或管理人、提取范围、人员地点时间、工具版本、来源路径、筛选条件、输出位置、数量、大小、失败项。原始对象、提取结果和封存载体的校验值分开。

## 电子数据检查

检材来源、编号、交接和封存状态、作业前校验值、检查目的和真实检索条件、写保护或副本、工具版本、实际执行的加载解析检索导出步骤、客观发现与推断分开、结束后的保存和重新封存。

多种模式同时发生时，先问是否分别成文。不要把不同时间、对象和人员混写。
